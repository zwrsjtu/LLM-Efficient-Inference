# LLM-Efficient-Inference

## 1. 实验环境
- 模型: Pythia-70M
- 设备: i7-12700h

| 指标 | 测试结果 |
| :--- | :--- |
| **Wikitext PPL (困惑度)** | 40.73 |
| **首字延迟 (TTFT)** | 0.0210 s |
| **单 token 耗时 (TPOT)** | 0.0084 s |
